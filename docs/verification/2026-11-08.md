# Recovery implementation verification — 2026-11-08

## Changes

- Restored saves before mounting gameplay. A failed storage read shows retry UI rather than replacing progress. Store-instance readiness and a mutation guard also protect saves during Expo Fast Refresh.
- Mission and tutorial eligibility are enforced in the store. Unknown mail IDs and invalid currency inputs are rejected.
- Offline income integrates boost expiry, pays 75%, caps each absence at four hours, and adds newly accrued income to an unclaimed reward. Online fractional CPS is retained between ticks.
- Achievements use persisted IDs and remain unlocked after spending, selling or dismantling. Existing saves infer eligible achievements when loaded.
- Oven copy count remains in the legacy `level` field. Separate `upgradeLevel` increases equipped click/CPS by 10% per enhancement, costs `floor(1000 * rarityTier^2 * 1.65^upgradeLevel)` cookies, and survives fusion/rebirth.
- New oven cores choose among Aurora, Opternal, Twilight and Phoenix. Existing assigned cores are retained. Infinity crystals cover a matching-crystal shortage during trait enhancement.

- Phone HUD uses two resource rows. Cookie dimensions derive from measured playfield space. Tutorial guidance occupies normal layout space. Home can scroll when vertical space is insufficient.
- Mission/settings/result/odds lists have constrained scrolling. Safe-area-context protects the shell, and modal padding includes safe-area insets.
- Added the requested `Powered By Kixha` footer. Background music defaults to off.

- Browser interactions: tap increases currency; tutorial advances after tapping; automation purchase updates count, CPS and tutorial progress; completed mission claim grants 500 cookies once; refresh restores the resulting balance; Fast Refresh preserves a saved one-cookie/tutorial-step-one state after a store-module edit.
- Music switch observed off. No audible BGM test was performed.

- Impeccable detector: no findings in the changed screen files. Browser still reports existing React Native Web shadow/pointerEvents deprecation warnings and a web animation-driver fallback warning.
